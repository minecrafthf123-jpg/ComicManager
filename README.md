# 漫画管理器（ComicManager）

[简体中文](README.md) | [English](README_EN.md)

一款支持 **JMComic API 搜索、详情查看与下载入库**的 Android 本地漫画管理应用。支持批量导入 ZIP 漫画、整理书架、缩放阅读、自动播放与阅读进度记录。

当前版本：**2.2.1**（`versionCode 7`）

系统要求：**Android 7.0（API 24）及以上**

## 主要功能

- 通过 API 搜索 JMComic 漫画、查看详情并下载到本地书架
- 支持简体中文与 English，可跟随系统语言，也可在书架菜单中手动切换
- 从系统文件选择器导入一个或多个 ZIP 文件，自动解压图片并生成封面
- 书架搜索、排序、批量选择、滑动勾选、删除重复项、导出与分享
- 默认上下连续滑动阅读，支持双指缩放和放大后拖动；可切换左右翻页
- 两种阅读模式均支持自动播放，可调整滚动速度或翻页间隔，自动保存阅读位置
- 阅读历史记录
- 从 ZIP 文件名识别关联编号，检查重复绑定并支持批量整理名称
- 可手动绑定或修改关联编号，并从书架进入对应详情

漫画图片、封面和数据库均保存在应用本地；项目不会自动上传个人书架数据。

## v2.2.1 更新重点

- 修复导入后书架反复显示旧的加入文件夹提示
- 支持点按底部导航跳转，四个页面仍可左右滑动切换
- 书架卡片尺寸统一，长标题超出后以省略号显示

## v2.2 更新重点

- JM 下载的漫画在书架置顶，下载组和本地组各自按当前排序方式排列
- 在书架多选后可将漫画加入已有文件夹，或命名并新建文件夹。同一本漫画可加入多个文件夹
- 第四页用通讯录式分组列表显示文件夹；删除文件夹或移出书目会保留书架中的漫画
- 统一用左右滑动在书架、阅读历史、JM 搜索、文件夹之间切换

## v2.1 更新重点

- 书架记住上次选择的排序方式，批量导入 ZIP 时显示已处理数量和当前解压进度
- JM 搜索支持键盘回车，多选或全选已加载的结果后可批量下载
- 在 JM 搜索结果页向左滑动可回到阅读历史
- 书架可通过 Android 分享面板发送选中的漫画 ZIP，多本漫画打包为一个合集
- 连续阅读可在 50%–400% 之间缩放
- 启用新的浅蓝底 Q 版角色图标

## v2.0 更新重点

- 移除内置网页及 JM 网站浏览、网页下载，仅保留 API 搜索、详情和原生下载
- 漫画详情页始终提供返回上级的按钮，下载入库后仍可返回
- 默认连续滑动阅读，支持双指缩放和放大后拖动
- 新增自动滚动和定时翻页；滚动速度为 0.05–1.5 屏/秒，翻页间隔为 2–20 秒，支持暂停及读到末尾自动停止
- 详情页可取消下载，取消后清理临时文件并恢复可下载状态
- 按真实图片总数显示详情页页数，不再将章节数量当作页数
- 书架多选模式支持拖动范围勾选、取消选择和边缘自动滚动

使用方法：在阅读器底部点击播放按钮，点击速度或间隔文字打开设置；切换阅读方式后按对应模式设置速度。在书架菜单中进入“选择漫画”，横向滑动或按住一项后拖动即可连续勾选；从已选项起手可连续取消选择。

## 开发与构建

### 环境要求

- Android Studio Hedgehog（2023.1.1）或更高版本
- JDK 17
- Android SDK 34
- Gradle Wrapper 8.5（项目内已配置）

### 常用命令

在项目根目录运行：

```powershell
# 单元测试
.\gradlew.bat testDebugUnitTest

# 生成 Debug APK
.\gradlew.bat assembleDebug

# 运行 Android Lint
.\gradlew.bat lintDebug
```

Debug APK 输出到：

```text
app/build/outputs/apk/debug/app-debug.apk
```

macOS 或 Linux 可将 `gradlew.bat` 替换为 `./gradlew`。如需生成正式发布包，请先在本机完成未入库的签名配置，然后运行：

```powershell
.\gradlew.bat assembleRelease
```

签名文件、签名配置、本机 SDK 配置和构建产物不应提交到仓库。

## 安装与升级

可以从 GitHub Releases 下载正式 APK。首次安装时，Android 可能会要求允许当前文件管理器或浏览器“安装未知应用”。

从旧版本直接覆盖升级时，新旧 APK 的应用签名必须一致：

- 使用相同正式签名的旧版本可直接升级到 2.2.1
- Debug 版或使用其他签名的版本无法直接覆盖正式版
- 如果系统提示签名冲突，只能先卸载旧版；卸载会清除应用私有目录中的书架、图片、阅读历史和进度

## 数据备份提醒

在卸载、换机或测试其他签名的安装包之前，请先使用应用内的“导出全部”或“导出所选”功能保存漫画 ZIP，并确认导出的文件可以正常打开。

导出的 ZIP 主要用于备份漫画图片及文件名中的关联编号，阅读进度、历史记录等应用内部状态不保证包含在内。重要数据建议另外保留一份副本。
