# 漫画管理器（ComicManager）

[简体中文](README.md) | [English](README_EN.md)

一款以 **JMComic 浏览、搜索、详情查看与下载入库**为主要功能，并配套本地文件管理与阅读能力的 Android 漫画应用。它也支持批量导入 ZIP 漫画、整理书架、记录阅读进度，以及翻页与连续滚动两种阅读方式。

当前版本：**1.1**（`versionCode 3`）

系统要求：**Android 7.0（API 24）及以上**

## 主要功能

- 浏览和搜索 JMComic 漫画、查看漫画详情，并将漫画下载后导入本地书架
- 支持简体中文与 English，可跟随系统语言，也可在书架菜单中手动切换
- 从系统文件选择器导入一个或多个 ZIP 文件，自动解压图片并生成封面
- 书架搜索、排序、批量选择、删除重复项、导出与分享
- 左右翻页和上下连续滚动两种阅读模式，自动保存阅读位置
- 阅读历史记录
- 从 ZIP 文件名识别关联编号，检查重复绑定并支持批量整理名称
- 可手动绑定或修改关联编号，并从书架进入对应详情

漫画图片、封面和数据库均保存在应用本地；项目不会自动上传个人书架数据。

## v1.1 更新重点

- 改进带编号 ZIP 的批量导入、去重与批量重命名流程
- 导出文件名保留关联编号，便于以后重新导入和恢复对应关系
- 修复从书架长按进入详情时可能沿用旧页面状态的问题
- 改进编号绑定对话框及重复编号冲突检查
- 修复旧版漫画目录路径，增强批量操作过程中的稳定性
- 加强 JMComic 客户端初始化的异常保护，降低启动或批量处理时闪退的概率
- 增加简体中文与 English 双语界面及应用内语言切换

## 开发与构建

### 环境要求

- Android Studio Hedgehog（2023.1.1）或更高版本
- JDK 17
- Android SDK 34
- Gradle Wrapper 8.5（项目内已配置）

### 常用命令

在项目根目录运行：

```powershell
# 单元测试
.\gradlew.bat testDebugUnitTest

# 生成 Debug APK
.\gradlew.bat assembleDebug

# 运行 Android Lint
.\gradlew.bat lintDebug
```

Debug APK 输出到：

```text
app/build/outputs/apk/debug/app-debug.apk
```

macOS 或 Linux 可将 `gradlew.bat` 替换为 `./gradlew`。如需生成正式发布包，请先在本机完成未入库的签名配置，然后运行：

```powershell
.\gradlew.bat assembleRelease
```

签名文件、签名配置、本机 SDK 配置和构建产物不应提交到仓库。

## 安装与升级

可以从 GitHub Releases 下载正式 APK。首次安装时，Android 可能会要求允许当前文件管理器或浏览器“安装未知应用”。

从旧版本直接覆盖升级时，新旧 APK 的应用签名必须一致：

- 使用相同正式签名的 1.0 版本可直接升级到 1.1
- Debug 版或使用其他签名的版本无法直接覆盖正式版
- 如果系统提示签名冲突，只能先卸载旧版；卸载会清除应用私有目录中的书架、图片、阅读历史和进度

## 数据备份提醒

在卸载、换机或测试其他签名的安装包之前，请先使用应用内的“导出全部”或“导出所选”功能保存漫画 ZIP，并确认导出的文件可以正常打开。

导出的 ZIP 主要用于备份漫画图片及文件名中的关联编号，阅读进度、历史记录等应用内部状态不保证包含在内。重要数据建议另外保留一份副本。
